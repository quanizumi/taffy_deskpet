# 永雏塔菲 — Windows 桌面宠物

贴在 Cursor 的 **Agents 窗口**上：大笑立绘，立绘保持静止。语音默认关闭，可在右键菜单里打开。

**双击 `start.bat` 即可运行**（首次会自动准备环境）。也可以双击已打包的 `dist\DeskPet.exe`，或：

```bat
python src\desk_pet.py
```

## 什么时候出现

塔菲认的是标题为「Cursor Agents」的那一个窗口，不认 IDE 编辑器。

| 情况 | 塔菲 |
|------|------|
| Agents 窗口开着 | 出现在窗口右下角，跟着窗口移动、缩放 |
| 正在用 IDE 编辑器 | 藏起来 |
| Agents 窗口关掉或最小化 | 藏起来 |
| 别的软件挡在前面 | 不盖住那个软件 |

Agents 窗口没开时，进程还在，托盘图标可以退出，或设置开机自启。开机自启只是登录后在后台等着，Agents 窗口一出现才会显示。

窗口无边框、背景透明，也不会抢走 Cursor 的焦点。右键可以改成以前的全局置顶；再点「回到 Cursor 窗口里」会回到只贴 Agents 窗口。

## 操作

| 操作 | 效果 |
|------|------|
| 左键拖动 | 在 Agents 窗口里移动；松手后记住离最近那个角的距离。按住时立绘会轻轻压扁 |
| 左键单击 | 刷新额度、换一句台词 |
| 滚轮 | 缩放大小（气泡一起缩放） |

右键菜单：

| 菜单 | 效果 |
|------|------|
| 调整大小 | 小 / 中 / 大 / 很大 |
| 脱离 Cursor，全局置顶 | 离开 Agents 窗口，改成始终浮在所有软件上面 |
| 回到 Cursor 窗口里 | 从全局置顶回到 Agents 窗口（只在已脱离时出现） |
| 开机自启 | 登录后自动在后台等待 Agents 窗口；已开启时菜单变成「取消开机自启」 |
| 开启语音 / 关闭语音 | 循环播放或停掉语音 |
| 刷新额度 | 立刻再查一次用量 |
| 隐藏额度气泡 / 显示额度气泡 | 只藏气泡，立绘还在 |
| 退出程序 | 结束进程。Agents 窗口没开时，也可以在托盘图标上退出 |

## 额度气泡

头顶气泡读取本机已经登录的 Cursor，不需要另外填写密钥。大约每 60 秒刷新一次；右键「刷新额度」会立刻再查。左键单击也会刷新，并换一句台词。

气泡跟 Cursor 设置页「Included in Pro」的两档用量走，百分比四舍五入成整数，和页面上的 “5% used” 同一套：

| 位置 | 内容 |
|------|------|
| 顶部 | **Cursor**（Cursor Models）和 **其他**（Other Models）各自用了多少 |
| 两根条 | 同上，两档各一根 |

套餐美元（includedSpend / limit）不拿来当已用百分比。情绪按这两档里更高的那个走：

| 占用 | 塔菲 |
|------|------|
| 不到 50% | 平时的气泡颜色 |
| 50%–80% | 台词换一档 |
| 80%–95% | 气泡变橙，头顶冒汗 |
| 95% 或任一到顶 | 气泡变红；这句台词留到再点一下 |

找不到本机 Cursor 登录时，气泡写「没找到 Cursor 登录」。登录过期会提示重新打开 Cursor。网络抖一下时沿用上一份数字，不把旧额度清掉。右键可以隐藏或重新显示气泡。

## 语音

启动时不播放。右键「开启语音」才会循环播放 `assets/9月4日.mp3`，再点「关闭语音」停止。左键单击不会把声音打开。

## 一键启动

双击 `start.bat`。脚本会：

1. 检测本机 Python 3.9+（没有则尝试用 winget 安装）
2. 在项目目录创建 `.venv` 虚拟环境
3. 安装运行依赖（PySide6 Essentials）
4. 启动桌面宠物

首次需要联网，可能要等几分钟；之后再双击会很快。

## 环境依赖

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 |
| Python | 3.9 及以上（可由启动脚本自动安装） |

Python 包（见 `requirements.txt`）：

| 包名 | 版本 | 用途 |
|------|------|------|
| PySide6 | >= 6.6.0 | Qt GUI 与音频（启动脚本会安装） |
| pyinstaller | >= 6.0.0 | 打包为 EXE（仅开发/打包需要） |

运行资源：

| 文件 | 用途 |
|------|------|
| `assets/character_cutout.png` | 透明立绘 |
| `assets/9月4日.mp3` | 循环语音 |
